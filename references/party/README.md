# party —— 党建 / 组织系统源

党建、组工、党员教育类网站：用于把「基层治理（街乡吹哨、部门报到）、试点名单、党建案例」等稿件的**官方口径版本**捞出来，与搜狗微信（`../wechat/README.md`）互为验证。另收一个**党史文献源**（中央党史和文献研究院 `dswxyjy.md`）：要找党的文献/年谱/大事记/党刊**原文**时用它，它的站内检索 API 直接返回正文。每个 host 一个文件；`✅/⚠️/❌` 均以本机 curl 实测为准（日期见各文件 `实测` 段）。

## 文件一览

| 文件 | 来源 | 用途 | 状态 |
|---|---|---|---|
| `dangjian.cn.md` | 中宣部主管·《党建》杂志社 | 标题级检索（`pageArticles.js` JSON 接口）；2018–2020 老稿链接多已 404 | ✅ 只走 http |
| `cpc.people.com.cn.md` | 人民网 | 标题/全文检索（`search.people.cn` JSON API），结果跨人民网全站 | ✅ 免登录 |
| `12371.cn.md` | 中组部党员教育中心 | 案例/课件形态材料（从不给单位名单） | ✅ 课件可下 |
| `bjdj.gov.cn.md` | 北京市委组织部 | 无站内检索，文章 ID 可小范围枚举 | ✅ curl 直读 |
| `cdcghy.com.md` | 顺义区委组织部（网站镜像） | 无站内检索，2018 稿仍在 | ✅ curl 直读 |
| `dswxyjy.md` | 中央党史和文献研究院 | `POST search.peopletech.cn/…/searchTalk`（标题+全文，**返回正文原文**）；图书库只有书目+图片翻页 | ✅ 匿名可用 |

## 选路

1. **找 2018–2020 基层稿**：搜狗微信（公众号原文，`../wechat/weixin.sogou.com.md`）→ 需要网页版/转载时用 `dangjian.cn` 检索（**记得验活，老链接会 404**）→ 用 `cpc.people.com.cn` 全文检索补人民网系转载 → `bjdj.gov.cn` / `cdcghy.com` 直读补市级、区级原发。
2. **要「案例 / 课件」形态**：`12371.cn`（只给数量，不给名单，别指望查单位清单）。
3. **要市级组工原发**：`bjdj.gov.cn`（无检索 → 靠文章 ID 枚举或站外 `site:` 搜索）。
4. **要权威引文口径**：优先 `cpc.people.com.cn`（人民网）与 `dangjian.cn`（中央党刊网）。
5. **要「党的文献 / 年谱 / 大事记 / 党刊文章」原文**：走 `dswxyjy.md`（中央党史和文献研究院）—— `POST search.peopletech.cn` 检索中台，`contentOriginal` 直接就是正文全文；命中量级示例：`年谱` 881 条、`周恩来` 2,639 条。图书（《建国以来重要文献选编》等）去 `ebook.dswxyjy.org.cn`，但那里只有书目 + 图片翻页，取不到文本。
6. **「党史网」`zgdsw.org.cn` 已失效**：2026-10-03 实测 `www.zgdsw.org.cn` = **NXDOMAIN**、apex 无 A 记录，curl 三次 000 —— 该机构已并入中央党史和文献研究院，党史稿改从 `dswxyjy.org.cn` 站内检索 + `cpc.people.com.cn` 党史频道两条路取。

关键词模板（`街乡吹哨 部门报到`、`{区} {单位} 试点`、`{单位} 2018年` 等）与「年份词放量法」见仓库根 `SKILL.md`。可用站内检索都**没有可靠的日期过滤**（`dangjian.cn` 无日期参数；`people.cn` 的 `startTime/endTime` 见 `../media/people.com.cn.md`；`dswxyjy` 的 `startTime` 被检索页写死在 2018-03-01、无法按年收窄）→ 仍用年份词放量。

⚠️ **2018 年课题注意**：人民网站内检索索引只覆盖约 **2021 年至今**（同日实测 2020 及更早 = 0 条），`dangjian.cn` 索引里有老稿但**链接多已 404**。找 2018 年稿件仍以搜狗微信为主通道，本目录站点用于「补转载 / 补官方口径」，不是 2018 语料的主力。
