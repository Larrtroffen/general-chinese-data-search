# xzqh.org —— 区划地名网乡镇名录

- 去哪找：逐区页面 `http://xzqh.org/show/china/2019/11/{6位区县码}.html`（省级 11=北京）。
- 什么时候用：要逐区（区县级）的街道/镇/乡完整名录，作为建"检索单位清单"的底本。
- 怎么搜：按区县代码拼 URL；页面中「政区划分」段为**转载国家统计局统计用区划代码表**的完整名录。
  ```
  http://xzqh.org/show/china/2019/11/110101.html   东城区
  http://xzqh.org/show/china/2019/11/110105.html   朝阳区
  http://xzqh.org/show/china/2019/11/110119.html   延庆区
  ```
  ```bash
  curl -s -m 25 'http://xzqh.org/show/china/2019/11/110101.html'
  ```
- 覆盖：逐区街道/镇/乡名录（2019 年版页面）；2019 年与 2018 年北京乡级区划一致，可直接作 2018 年名录底本。
- 门槛：免费，无需登录。
- 实测：原卡未记录日期（本机 curl）；逐区页面 `curl` 可取（编码 GBK/UTF-8 视页面而定）。
- 上游：区划地名网 `http://xzqh.org/`（非官方）。

## 细节

### 页面格式

- 页面中「政区划分」段为**转载国家统计局统计用区划代码表**的完整名录（街道/镇/乡逐条列出）。
- 2019 年与 2018 年北京乡级区划一致，可直接作 2018 年名录底本（需注意：2018 年通州新设潞源、通运两街道，2017 及以前为 331，2018 起为 333）。
- 编码 GBK/UTF-8 视页面而定（`iconv -f gb18030` 兜底）。

### 解析要点

- 名录行通常为"街道列表：xxx、yyy、zzz；镇列表：…；乡列表：…"的段落文本，逐条用顿号切分。
- 带括号的名称（如"南磨房乡（南磨房地区）"）保留括号用于归一化比对。
- 逐区求和后与年鉴总数核对（见 `stats.gov.cn.md`）。

## 坑

- 若目标年份与页面年份不一致，先核对是否存在区划调整（撤镇设街、街道拆分）。
- 该站非官方，名录用于建"检索单位清单"足够；正式引用口径建议标注"转自国家统计局统计用区划代码"。
