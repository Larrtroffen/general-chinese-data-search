# 农产品成本收益资料汇编 —— 成本收益数据入口

- 去哪找：**国家发改委价格司《农产品成本调查简报》栏目** `https://www.ndrc.gov.cn/fggz/jggl/dfgz/`（发布《汇编》年度出版消息与调查简报，免费）；**知网·中国经济社会大数据研究平台**的年鉴库（检索/组配表格，见本层 `cnki-data.md`）；**商业年鉴下载站**——统计年鉴下载站 `https://www.tjnjdata.com/`（旧域 `tjnj.net`）、年鉴数据网 `http://www.nianjiandata.com/`、`acadcn.cn`、`zldatas.com` 等。
- 什么时候用：要**每亩产量、产值、总成本、售价、收益、成本利润率**（稻谷/小麦/玉米/大豆/棉花/油菜籽/糖料/生猪/蔬菜…）；写农业经济实证、成本收益面板、政策评估；要各卷收录年度的**近六年**成本收益简明序列（随卷浮动，如 2024 卷为 2018 年以来）。
- 怎么搜：三条路，按可得性排——
  1. **官方免费（只有消息/简报，无全书表）**：`https://www.ndrc.gov.cn/fggz/jggl/dfgz/` 栏目列表形态，正文为《农产品成本调查简报》第 N 期（如 2024 年第 13 期即《汇编2024》出版公告）；分省细项可再查各省发改委「成本调查/价格管理」栏目。
  2. **知网平台（表格数值，需登录）**：进入中国经济社会大数据研究平台后按「年鉴 → 全国农产品成本收益资料汇编 → 年份 → 表格」取数（API 与门槛同 `cnki-data.md`：匿名接口返 471，需机构/个人账号）。
  3. **商业下载站（PDF/Excel，付费/积分）**：搜索引擎可见多家年鉴站整本出售，需注册/会员；**版权存疑，仅供线索**，正式引用请回官方口径或知网版本。
  结果形态：官方=HTML 简报正文；知网=在线表格（可导出）；商业站=PDF/Excel 下载链接（登录后）。
- 覆盖：《汇编》**逐年卷**，收录**上一年**50 余种农产品成本收益 + 2018 年以来六年简明数据（如《汇编2024》收录 2023 年数据、《汇编2021》收录 2020 年数据）；数据源为 **31 个省区市、1553 个县、6.6 万余个农调户**的调查汇总；覆盖粮、棉、油、糖、肉、菜及地方特色农产品，分种植业/畜牧养殖业，含产量、产值、成本、售价、收益、利润；**分全国与分省**。上游调查自 **1953 年**起持续至今。
- 门槛：官方栏目**免费、无需登录**；全书**无免费 CSV**——知网需机构 IP/账号，商业站需注册/付费。
- 实测：2026-10-03，macOS arm64，curl 8.x（桌面 UA，20 s 超时）——`https://www.ndrc.gov.cn/fggz/jggl/dfgz/202408/t20240802_1392187.html` → 200，正文确认《全国农产品成本收益资料汇编2024》由国家发改委编印出版、收录 2023 年 50 余种农产品成本收益及 2018 年以来六年简明数据，来源为 31 省区市/1553 县/6.6 万余农调户；`https://www.tjnjdata.com/navibooklist-n3025120502-1.html`（由 `tjnj.net` 跳转）→ 200，商业站整本《2025年…汇编》PDF/Excel 需登录/注册；`http://www.nianjiandata.com/index.php/books-quanguo-nongchanpin-chengbenshouyi-ziliaohuibian.html` → 200，含《汇编》收录说明与分七部分目录；`https://data.oversea.cnki.net/yearBook/single?id=N2025020018` → **404**（该 id 不适用，知网年鉴取数改以平台内检索为准）。
- 上游：国家发改委价格司《农产品成本调查简报》栏目 `https://www.ndrc.gov.cn/fggz/jggl/dfgz/`；知网·中国经济社会大数据研究平台（见 `cnki-data.md`）。

## 细节

### 《汇编》结构（据年鉴数据网转载的官方说明）

分**七个部分**：① 综合（成本收益汇总）；② 分品种成本收益；③ 分省分品种；④ 种植业/畜牧养殖业明细；⑤ 地方特色农产品；⑥ 简明数据（近六年）；⑦ 附录（指标解释等）。指标含产量、产值、总成本（物质与服务费用+人工+土地）、售价、现金收益、净利润、成本利润率。

### 分品种与分省入口

- 品种：稻谷、小麦、玉米、大豆、棉花、油菜籽、花生、甘蔗、甜菜、烤烟、生猪、肉鸡、蛋鸡、奶牛、淡水鱼、大中城市蔬菜等 50 余种。
- 分省：31 省区市；分省数据散见各省发改委「成本调查」栏目与省级统计年鉴，口径可能与全国卷略有差异。

## 坑

1. **官方只有简报，没有全书数字**：发改委栏目给的是出版消息与调查简报，**逐品种表格在书里**；指望免费 CSV/Excel 会落空。
2. **商业站版权存疑**：多家「年鉴下载站」内容质量与更新年份不可核，且需付费/积分；引用前务必核对是不是官方卷、年份版本对不对。
3. **《汇编》年份 = 数据年 + 1**：`《汇编2024》` 收录的是 **2023 年**数据，作者/表名别写错年份。
4. **知网 id 不稳定**：`data.oversea.cnki.net/yearBook/single?id=…` 直链会 404，应走平台内检索/导航，不要硬编码 id（同 `cnki-data.md` 的坑）。
5. **知网与商业站的字段名/单位不一**：成本口径有「每亩」与「每50公斤主产品」两套，跨源拼接前先对齐口径。
6. **分省数据与全国卷可能对不上**：全国卷不含港澳台（官方说明已注明），分省口径差异需在脚注说明。
