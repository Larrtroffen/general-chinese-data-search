# 农业农村统计 —— 部委数据门户与粮食储备

- 去哪找：**农业农村部数据开放门户** `https://data.moa.gov.cn/`（→ `/nyb/pc/index.jsp`）、规划计划 `https://www.moa.gov.cn/gk/ghjh_1/`；**国家粮食和物资储备局「粮食数据」** `https://www.lswz.gov.cn/html/zmhd/lysj/index.shtml`；**国家粮油统计信息系统** `http://lytjxx.lswz.gov.cn:8181/`；**《中国农村统计年鉴》书目页**（国家统计局「统计出版物」）`https://www.stats.gov.cn/zs/tjwh/tjkw/tjzl/`，如 2021 卷 `.../202302/t20230215_1907997.html`。免费在线数值兜底 → 本层 `data.stats.gov.cn.md`（国家数据·农业指标）与 `ministry-stats.md`（部委栏目表）。
- 什么时候用：要**农业农村部口径**的年度/月度数字（农林牧渔业产值、粮食/生猪产量、价格指数、进出口…）；要**粮食收购价格周报、粮油市场价格周报、夏/秋粮收购进度**；要《中国农村统计年鉴》的出版/购买口径与数据范围；要粮油统计直报线索。
- 怎么搜：三部——
  - **① 粮食数据栏目**（最可用）：`https://www.lswz.gov.cn/html/zmhd/lysj/index.shtml` 是「栏目列表 → 文章页」静态结构，含三类定期报告：`全国主要粮食品种收购价格周报`、`主要粮油商品市场价格周报`、`{年份}年度夏季/秋粮收购进度`；文章 URL 形如 `/html/zmhd/lysj/{YYYY-MM}/{DD}/content_{id}.shtml`。**列表可 curl，正文价格表是 PNG 图片**（见坑 1）。
  - **② 农业农村部数据门户**：首页 ✅，但数据集目录由 JS 渲染，`/misportal/public/agriculture200Helper.jsp` 命中防爬挑战（302 → 混淆 JS），**curl 取不到目录，需浏览器**；价格指数部分见 `agri-price.md`。
  - **③ 年鉴**：《中国农村统计年鉴》**无免费全文**——国家统计局只挂**书目介绍页**（作者=农村社会经济调查司、书号、定价），全书走中国统计出版社/知网（见 `agri-cost-benefit.md` 同法的知网入口 `cnki-data.md`）；免费在线全文只到**《中国统计年鉴》** `https://www.stats.gov.cn/sj/ndsj/{年}/indexch.htm`（含农业章）。
- 覆盖：粮食数据栏目——**周报**（收购价/市场价格，逐年逐周）+ **月度**收购进度，最新到 2026-09；农业农村部门户为数据目录入口（口径/粒度随数据集，年报/月报为主）；《中国农村统计年鉴》年度卷，收录**上年**全国及分省农村社会经济统计（2021 卷收录 2020 年数据）。
- 门槛：粮食数据栏目与年鉴书目页**免费、无需登录**；**国家粮油统计信息系统需账号**（地方/企业直报）；数据门户目录需浏览器。
- 实测：2026-10-03，macOS arm64，curl 8.x（桌面 UA，20 s 超时）——`https://data.moa.gov.cn/` → 200（跳 `/nyb/pc/index.jsp`）；`/misportal/public/agriculture200Helper.jsp` → **302 空体**（防爬，跟随重定向取不到内容）；`https://www.lswz.gov.cn/` → 200；`/html/zmhd/lysj/index.shtml` → 200，含《全国主要粮食品种收购价格周报（9月22日）》《主要粮油商品市场价格周报（9月23日）》《2026年度夏季粮油收购进度（8月31日）》等；周报正文页 `.../2026-09/23/content_295396.shtml` → 200，价格数据落在 `<img src="295396/images/c54ab9275c2b40e4a4c8073504635b0a.png">`；`http://lytjxx.lswz.gov.cn:8181/` → 200（Vue SPA，`__NROS__` 平台，需登录）；`https://www.stats.gov.cn/zs/tjwh/tjkw/tjzl/202302/t20230215_1907997.html` → 200（《中国农村统计年鉴—2021》书目，定价 268 元）。
- 上游：农业农村部 `https://www.moa.gov.cn/`、数据开放门户 `https://data.moa.gov.cn/`；国家粮食和物资储备局 `https://www.lswz.gov.cn/`；国家统计局统计出版物 `https://www.stats.gov.cn/zs/tjwh/tjkw/tjzl/`。

## 细节

### 粮食数据栏目（`/html/zmhd/lysj/`）三类报告

| 报告 | 频率 | 形态 | 备注 |
|---|---|---|---|
| 全国主要粮食品种收购价格周报 | 周 | 正文多为图片 | 小麦/稻谷/玉米/大豆等收购价 |
| 主要粮油商品市场价格周报 | 周 | **PNG 图片** | 粮油批发/零售价 |
| 夏季·秋粮收购进度 | 月 | 正文/表 | 分省收购量与进度 |

栏目结构：`政民互动 > 粮食数据 > 粮食价格 > 市场价格`；直属单位另有**国家粮油信息中心**、**国家粮食和物资储备数据中心**（门户仅机构介绍页，无独立数据站点）。

### 农业农村部相关站点

- 数据开放门户 `data.moa.gov.cn`（`/nyb/pc/index.jsp`）：门户说明含「农产品批发价格200指数优化调整说明」（2026-05-25 上线）。
- 业务管理 `https://ywglmh.moa.gov.cn`、政务服务 `https://zwfw.moa.gov.cn`、中国农业农村信息网 `https://www.agri.cn`、中国乡村振兴发展中心 `https://xczx.agri.cn`、访问分析 `https://report.moa.gov.cn/report/index.html`。
- 农产品批发价格 200 指数接口与市场名录 → 见本层 `agri-price.md`。

## 坑

1. **粮食周报的数值是图片**：栏目列表能解析，但正文价格表为 PNG（`.../images/*.png`），**拿不到结构化数字**，需 OCR 或改走 `agri-price.md` 的价格接口。
2. **数据门户防爬**：`data.moa.gov.cn` 主站 200，但目录页 `agriculture200Helper.jsp` 返 302 到混淆 JS（无 Cookie/浏览器拿不到），别把主站可达当成目录可取。
3. **两个「粮油统计」域名易混**：`lytjxx.lswz.gov.cn:8181` 是**直报系统（需登录）**，不是公开查询；公开数据在门户「粮食数据」栏目。
4. **《中国农村统计年鉴》不是免费年鉴**：国家统计局官网只有书目页；勿与**免费全文的《中国统计年鉴》**（`/sj/ndsj/`，含农业章）混为一谈。
5. 粮食周报 URL 的日期段是**发布日**（`2026-09/28`），与报告周期（9月22日）不同，按标题检索比按日期拼 URL 稳。
6. 农业农村部/粮食局站改版较勤，栏目路径会变；引用数字请落回**文章标题+发布日**。
