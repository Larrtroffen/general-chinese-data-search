# china-io-table —— 中国投入产出表

- 去哪找：**国家数据（国家统计局发布库）** `https://data.stats.gov.cn/` 首页「投入产出表」栏目；官方「如何查找历年投入产出表？」问答 `https://www.stats.gov.cn/hd/lyzx/zxgk/202405/t20240524_1953627.html`；《中国统计年鉴》国民经济核算章节 `https://www.stats.gov.cn/sj/ndsj/{年份}/`；省级见各省统计局「投入产出调查」专题（例：重庆 `https://tjj.cq.gov.cn/ztlm_233/trccdc/`）；学术整理版省级 IO 见 `../env/ceads.net.md`。
- 什么时候用：要**全国投入产出表 / 投入产出延长表**（中间使用、最终使用、增加值、总产出矩阵）、投入产出部门分类、完全消耗系数；做产业结构、增加值率、碳/就业足迹、CGE/SAM 标定；要**分省** IO 表。
- 怎么搜：
  - **国家数据**首页列出「投入产出表」年份节点（2002、2005、2007、2010、2012、2015、2017、2018、2020、2023），点入为 SPA 表格，交互查询/导出 —— **需浏览器**（接口与 `data.stats.gov.cn.md` 同族，`easyquery.htm` 已 403）。
  - **年鉴 xls 直链规律**：`https://www.stats.gov.cn/sj/ndsj/{年}/html/{表号}.xls`（例 2013 年鉴 `…/2013/html/Z1102C.xls`）；IO 表仅**逢 2、逢 7 年份**进年鉴，逢 0、5 年份为**延长表**（官方问答口径）。
  - **省级**无统一中央入口：到目标省统计局「投入产出调查/投入产出表」专题页取 xls（重庆 2020 表 `…/ztlm_233/trccdc/202311/P020231103610548296211.xls`；部门分类表同目录）。
- 覆盖：全国 **2002 起**（官方问答：国家数据发布库可查 2002 年以来的全国投入产出表与延长表；逢 2/7 为调查年、逢 0/5 为延长表，另 2018、2023 亦有表）；部门口径以 **42 部门（I 级分类）** 为主，年鉴/简表为 17 部门，年份不同另发更细版本；分省为各省自行发布，年份与部门数不一。
- 门槛：**免费**；国家数据为 SPA（需浏览器交互/导出），年鉴 xls 与各省 xls 直链可 curl；CEADs 省级 IO **需注册登录**。
- 实测：2026-10-03，macOS arm64，curl 8.x（桌面 UA、`-L`、20 s）——`https://data.stats.gov.cn/` `200`（SPA，302→`/dg/website/page.html#/pc/national/home`）；`…/dg/website/publicrelease/web/external/new/queryIndexTreeAsync?pid=&code=3` `200` 返回「年度数据」指标树（其中无独立「投入产出表」节点）；旧 `easyquery.htm` `403`（UrlACL，见 `data.stats.gov.cn.md`）。官方问答页 `…/202405/t20240524_1953627.html` `200`，正文三途径齐全。年鉴样例 `https://www.stats.gov.cn/sj/ndsj/2013/html/Z1102C.xls` → `206 application/vnd.ms-excel`（仅取头，未核内容）。省级样例 `https://tjj.cq.gov.cn/ztlm_233/trccdc/202311/P020231103610548296211.xls` → `206 application/vnd.ms-excel`（2020 年 42 部门表）。❌ 旧 2020 表附件直链（`…/xw/tjxw/tzgg/202302/P0…xls`）已 `404`。
- 上游：国家统计局「国家数据」`https://data.stats.gov.cn/`；《中国投入产出表》/《中国地区投入产出表》（中国统计出版社）；国家统计局在线问答 `https://www.stats.gov.cn/hd/lyzx/zxgk/trccb`。

## 细节

### 官方三条取数途径（摘自 2020-11-30 答复，2026-10-03 本机复核页面可达）

| 途径 | 可用内容 |
|---|---|
| 出版物《中国投入产出表》 | 1987 年以来**逢 2、逢 7** 年份，资料最全 |
| 《中国统计年鉴》「国民经济核算」章节 | 1987 年以来逢 2/7 的全国 IO 表 + 逢 0/5 的延长表 |
| **国家数据发布库**（`data.stats.gov.cn`） | **2002 年以来**全国投入产出表与延长表 |

### 国家数据「投入产出表」年份节点（首页栏目所载）

`2023 · 2020 · 2018 · 2017 · 2015 · 2012 · 2010 · 2007 · 2005 · 2002`（同年另有「资金流量表」系列，勿混）。

### 年鉴 xls 直链规律

```
https://www.stats.gov.cn/sj/ndsj/{年鉴年}/html/{表号}.xls   # 例 2021 年鉴 /sj/ndsj/2021/html/…
https://www.stats.gov.cn/sj/ndsj/{年鉴年}/indexch.htm       # 章节目录（静态站在 /html/ 下）
```
- 年鉴年 = 数据年 + 1；IO 表在「国民经济核算」章，表号随年鉴版式变动，**回目录页解析**，别套固定表号。

### 分省 IO

- 《中国地区投入产出表》为 NBS 出版物（如 2012、2017 版，封面/书目页在 `stats.gov.cn/zs/tjwh/tjkw/tjzl/`）。
- 各省统计局自建「投入产出调查」专题：搜索「{省}统计局 投入产出表」→ 进专题页解析 xls 附件（附件名多为 `P0{时间戳}.xls`，需从 HTML 抓）。
- 要**统一的省级 IO 面板**（含碳排放配套）用 CEADs：`../env/ceads.net.md` 的 `/data/input-output-tables/`（需注册）。

## 坑

1. **国家数据是 SPA**：curl 首页只拿到壳（3 KB），表格在 XHR 之后；社区常见的 `easyquery.htm?cn=…` 旧接口已全站 403。取数逻辑见 `data.stats.gov.cn.md`（新外部接口族）。
2. **年鉴 xls 表号会变**：`Z1102C.xls` 这类表号每版重排，必须从当年 `index*` 目录解析链接，勿硬编码。
3. **IO 表与延长表年份规则不同**：逢 2/7 = 调查表（全口径），逢 0/5 = 延长表（推算），二者不可当同一年度序列直接连用。
4. **部门口径不统一**：42 部门 vs 17 部门 vs 更细分版，跨表/跨年比较前先对齐部门分类表（每套表都随表发布「投入产出部门分类」）。
5. **旧静态附件会失效**：NBS 早年在「通知公告」挂的 2020 表 xls 现已 404，别引死链；以国家数据平台当前节点为准。
6. 引用省级表要写清**编制省份 + 数据年 + 部门数 + 价格口径**（生产者价格/购买者价格），各省差异大。
7. 学术口径的省级 IO 与官方表**不完全等价**（CEADs 会做部门归并与平衡调整），正式引用注明来源与版本。
