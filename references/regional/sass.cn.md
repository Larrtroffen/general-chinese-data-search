# sass.cn —— 四川省社会科学院

- 去哪找：`http://www.sass.cn/`（**HTTPS 不可用**，见坑）。
- 什么时候用：要四川省级社科研究动态与机构；要「四川省社会科学院文献信息中心」（院图书馆/文献开发/网络与数字服务）线索。
- 怎么搜：栏目 ID 制，文章形如 `/<栏目ID>/<文号>.aspx`（如 `126/80305.aspx`、`104/81447.aspx`）；按机构/研究所/智库栏目浏览。
- 覆盖：四川社科院新闻、研究所动态、智库建设、文献信息中心；**无独立数据检索接口**。
- 门槛：免费、免登录。
- 实测：2026-10-03，macOS arm64，curl 8.x 桌面 UA：`http://www.sass.cn/` → 200（55,466 B，`<title>四川省社会科学院`）；`https://www.sass.cn/` → **000**（HTTPS 不通）。
- 上游：`http://www.sass.cn/`（四川省社会科学院）。

## 坑

1. **只服务 http**：HTTPS 连不上，脚本用 `http://`，别再 `-L` 强跳 https。
2. 域名 `sass.cn` 与上海社科院 `sass.org.cn` **极易混淆**——四川无 `.org`，上海有 `.org`。
3. 老域名 `scsky.cn` 已被**影视站占用**（实测 title 为盗版影视站），别再用它定位川社科院。
4. 「文献信息中心」是院内图书文献机构，公开页只有服务介绍，**没有对外开放的数据下载**。
