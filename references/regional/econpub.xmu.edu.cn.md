# econpub.xmu.edu.cn —— 厦大经济学科研究共享平台

- 去哪找：`https://econpub.xmu.edu.cn/elib/`；数据集详情 `/elib/ds_detail/{id}/`；共享数据集&代码 `/elib/ownds/`；提交数据集 `/elib/mycommit/add/`；申请数据库 `/elib/apply/`。
- 什么时候用：要经济学科**整理好的数据集与代码**（县域统计年鉴、城市统计年鉴面板、住户调查年鉴、城镇生活与价格年鉴、市场化指数…）；要复现论文的数据/程序。
- 怎么搜：首页把数据分「授权数据库 / 公开数据库 / 授权软件」三块（`#featured-data` 等锚点），列表与详情页为服务端 HTML；**下载/申请**走 `/elib/apply/`（微信安全认证）。
- 覆盖：经济学科共享数据集/代码（示例：id 20 中国县域统计年鉴 2000–2019；id 22 2004–2020《中国城市统计年鉴》面板；id 24 中国（农村）住户调查年鉴 2000–2021；id 25 中国城市(镇)生活与价格年鉴 2006–2012；id 26 中国市场化指数；id 27 营养改善计划论文数据/程序）。
- 门槛：目录浏览可见；**下载/申请需微信扫码安全认证 + 厦大统一账户**（经济学科教职工/学生）。
- 实测：2026-10-03，macOS arm64，curl 8.x 桌面 UA：`https://econpub.xmu.edu.cn/elib/` → 200（40,414 B，`<title>厦门大学经济学科研究共享平台`）；`/elib/ds_detail/22/` → 200（15,712 B）；`/elib/ownds/` → 200（14,443 B）；`/elib/apply/` → 200（10,156 B，`<title>微信验证-账户管理-用户中心`，正文要求「微信扫码安全认证」）；`/elib/api/search?q=yearbook`、`/elib/api/info/version` → **404**（非标准 Dataverse API）。
- 上游：`https://econpub.xmu.edu.cn/elib/`（厦门大学经济学院/王亚南经济研究院）。

## 坑

1. 申请页是**微信安全认证**：非微信环境 curl 只能拿提示页；厦大校外用户基本受限。
2. 页面虽引用 `dv_*` 脚本，但 `/elib/api/...` 实测 404——**不是可直连的 Dataverse API**，别套 Dataverse 端点。
3. 数据集 ID 是流水号（20/22/24…），**不连续**，别按 ID 遍历。
