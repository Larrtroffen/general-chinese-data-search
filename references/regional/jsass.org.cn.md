# jsass.org.cn —— 江苏省社会科学院与院内数据库导航

- 去哪找：首页 `http://www.jsass.org.cn/index.html`（站点 `/` 是 990 B 的 JS 跳转壳）；智库平台 `http://www.jsass.org.cn/jgsz/zkpt/`；图书馆「数据库资源」`http://www.jsass.org.cn/jgsz/kfjg/tsg_142/bgzy/sjkzy/`。
- 什么时候用：要江苏本地研究机构与智库线索（大运河文化带建设研究院、江苏文脉研究院、区域现代化研究院、江苏省金融研究院、人工智能与社会科学创新中心）；要一份「社科院内可用商业数据库清单」作选路参考。
- 怎么搜：站点是静态 HTML + 栏目目录制（`/<栏目>/<年>/<月>/t<日期>_<id>.html`）；图书馆「数据库资源」页直接列出各库入口。
- 覆盖：江苏社科院机构/成果/学者；图书馆列出的数据库含中国知网、超星读秀/百链/发现、国研网（**江苏省社科院专供版** `g.drcnet.com.cn/u/828185/`）、北大法宝、人大复印资料、万方、中华书局「籍合网」、维普（新时代社会发展理论研究平台）、中国近代资源全库（`cnbksy.com`）、国家数字图书馆。
- 门槛：站点**免费**；图书馆数据库**院内 IP/账号**（页面另有内网镜像 `49.77.204.86`）。
- 实测：2026-10-03，macOS arm64，curl 8.x 桌面 UA：`http://www.jsass.org.cn/` → 200 但仅 990 B（`<title>社科院`，`navigator.platform` 判断后 `window.location.href="./index.html"`）；`…/index.html` → 200（50,293 B，`<title>江苏省社会科学院`）；`/jgsz/zkpt/` → 200（14,411 B）；`/jgsz/kfjg/tsg_142/bgzy/sjkzy/` → 200（15,598 B）。
- 上游：`http://www.jsass.org.cn/`（江苏省社会科学院）。

## 坑

1. 首页 `jsass.org.cn/` 是**平台判断跳转壳**，curl 只拿 990 B；直接打 `/index.html`。
2. 图书馆页里 **`http://49.77.204.86/` 是内网 IP 镜像**，校外不可达；外网库（知网、国研网专供版等）同样需院 IP/账号。
3. 数据库资源页是**导航清单**，不含数据本体，也没有检索 API。
