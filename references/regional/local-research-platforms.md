# local-research-platforms —— 地方社科研究平台总表

省级/市级社科院的「数据中心」常是**院内资源门户**（图书馆 + 采购库 + 内网），并非公开数据站；本卡把这类入口与真正的公开地方研究平台分开列。

- 去哪找：见「细节」表。
- 什么时候用：要**市级/地方**的社科研究机构、智库成果或院内数据资源入口（广州、深圳、北京、上海）；要把「地方社科院数据中心」与「政府开放数据平台」区分开。
- 怎么搜：逐家进站；地方社科院多为静态栏目站，「数据中心」页只是把采购的知网/皮书等**院内资源**列出来，外网不可用。
- 覆盖：广州、深圳、北京、上海四地研究机构与相关公开平台（见下表）。
- 门槛：机构站免费；**院内数据资源需院 IP/VPN**；公开评估类平台免费。
- 实测：2026-10-03，macOS arm64，curl 8.x 桌面 UA，逐站 GET（状态见各行）。
- 上游：各平台官方入口。

## 细节

| 平台 | 入口 | 性质 | 本机实测 |
|---|---|---|---|
| 广州市社会科学院——数据中心 | `https://www.gzass.gd.cn/gzsky/channels/95.html` | 院内资源门户：WebVPN + CNKI + 中国经济社会大数据研究平台 + 皮书 + 国研网教育版 + 人大复印 + 读秀 + 国家哲社期刊库 + 院文献总库（内网 IP） | ✅ 页面 200；多数链接指向 `192.168.*` / 院内 WebVPN |
| 北京市社会科学院 | `https://www.bass.org.cn/` | 智库成果/重点成果/新型智库；**无独立数据中心**（页脚外链 `tjj.beijing.gov.cn`） | ✅ 200（62,014 B） |
| 深圳市社会科学网（市社科院/社科联） | `http://www.szass.com/index/` | 机构动态/成果；**仅 http** | ✅ http 200（35,158 B）；https 000 |
| 上海社会科学院信息研究所 | `https://iis.sass.org.cn/` | 数据实验室/研究中心挂靠（产业创新数据实验室、社会科学智能实验室） | ✅ 200 → `sass.org.cn.md` |

| 上海数据交易所 | `https://www.chinadep.com/` | 数据要素交易平台（非社科研究，但常被引作上海数据资源入口） | ✅ 200（80,395 B） |

- **地方开放数据平台**（`data.sh.gov.cn`、`data.beijing.gov.cn`、`opendata.sz.gov.cn` 等）是**数据本体门户**，已在 `../gov/gov_opendata.md` 收录，本卡不重复。
- **地方统计年鉴/公报**见 `provincial-yearbooks.md` 与 `../stats/tjj.beijing.gov.cn.md`。

## 坑

1. 「XX 社科院数据中心」≠ 公开数据站：广州该页全是**院内 WebVPN / 内网 IP**（`192.168.*`），外网只能看到清单。
2. 深圳站**只服务 http**（https 连不上）；北京社科院**没有**独立数据平台，别硬找。
3. 开放数林（`ifopendata.fudan.edu.cn`）是**评估/研究报告**平台，给的是指数与报告，不是原始数据。
4. 引用地方机构数据时先判「机构站 vs 开放数据平台 vs 统计年鉴」三条线，口径不同。
