# industry-yearbooks —— 行业年鉴在线入口分级

- 去哪找：行业年鉴没有统一门户。路径是「**行业协会官网 → 年鉴/统计资料栏目 → 商业年鉴库**」三级；本层各协会卡是前两级的索引。
- 什么时候用：要某个行业年鉴（钢铁/汽车/纺织/轻工/电子信息/医药/房地产）的整表数据，或先确认「这本年鉴网上有没有免费 PDF/在线查询」。
- 怎么搜：先按下面分级定位，再回对应卡片取数：

  **① 官网有在线入口（本机实测）**
  | 年鉴/资料 | 入口 | 形态 |
  |---|---|---|
  | 中国房地产年鉴 | `http://www.fangchan.com/yearbook/` | 年鉴解读/历年年鉴/查询三区块；**年鉴付费**（微店） |
  | 中国信息年鉴 | `http://www.cia.org.cn/data/data_index.htm` | 信息化指标页免费，完整数据走 `/dingyue_shuju.html` |
  | 中国医药统计年报 | `https://www.yytj.org.cn/subscribeReportList.aspx` | 目录/征订页；**付费征订** |
  | 轻工业统计资料 / 行业报告 | `http://www.clii.com.cn/ydbg/index.html` | 栏目免费，报告本体入口为 `#`（疑需登录） |

  **② 官网无免费数据入口（本机实测）**：中国钢铁工业协会门户（`chinaisa.org.cn` 统计发布栏目 JS 渲染、内容偏旧）、中国机械工业联合会机经网（`mei.net.cn` 无数据栏目）、中国电子信息行业联合会（`citif.org.cn` 纯 SPA）。

  **③ 官网本机不可达**：中国纺织工业联合会 `cntac.org.cn`（TLS 中断/空响应）、中国纺织经济信息网 `ctei.cn`（443 拒绝）。

  **④ 未验证**：中国汽车工业年鉴、中国纺织工业年鉴、中国钢铁工业年鉴的官网 PDF/在线查询情况（本次未逐条探测）。

- 覆盖：年度、行业大类粒度；官网一般只给目录/解读，**表格本体多在订阅库**。
- 门槛：官网解读免费；年鉴全文/表格需购买或机构 IP。
- 实测：2026-10-03，curl 桌面 UA：`fangchan.com/yearbook/` → 200，34 KB；`cia.org.cn/data/data_index.htm` → 200，42.5 KB；`yytj.org.cn` → 200，50 KB；`clii.com.cn/ydbg/index.html` → 200，33 KB；`cntac.org.cn` / `ctei.cn` → 连接失败 ❌。
- 上游：各行业协会与年鉴编辑部（见本层各卡「上游」行）。

## 细节

- **数值型年鉴库**（整表、可检索、跨年）走：`../stats/cnki-data.md`（知网·中国经济社会大数据研究平台，`valueSearch` 指标检索）、`../stats/epsnet.md`（EPS 数据平台）、`../stats/cei-drc.md`（中经网/国研网）。
- 国家统计年鉴（非行业年鉴）走国家统计局与 `../stats/tjj.beijing.gov.cn.md` 一类地方统计口径。

## 坑

1. **别假设官网有年鉴 PDF**：中文行业年鉴商业化程度远高于国家统计年鉴，免费在线表格是少数。
2. 年鉴引用要写「年鉴名 + 年份 + 表名 + 页码」；同名指标各年鉴口径差异大（如「销售产值」是否含税）。
3. 要最新数据先看**协会月报**（本层多数协会卡有，免费且比年鉴新），年鉴只用来补历史与口径。
