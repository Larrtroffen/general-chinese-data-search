# sac.net.cn —— 证券公司行业数据

- 去哪找：门户 `https://www.sac.net.cn/`（行业数据/统计信息栏目在门户导航内，路径随改版变动）。
- 什么时候用：要**中国证券业协会口径**的证券公司经营数据——行业/公司营业收入、净利润、总资产、净资产、客户资金、会员名录、从业人员、行业排名与年度经营分析报告。
- 怎么搜：门户为 CMS 站点（列表 → 文章 → 附件）。**2026-10-03 起处于停机维护**，全站（含子路径）统一返回「系统停机维护公告」页，正常期栏目路径未本机验证，**维护结束后再复核**。
- 覆盖：证券行业年度/月度经营数据与统计报告（覆盖年份以站内为准）；全国口径；会员/人员名录。
- 门槛：无（免费）；维护窗口内不可用。
- 实测：2026-10-03，桌面 UA curl——`GET https://www.sac.net.cn/` `200/21,148 B`，`<title>2026年国庆节放假期间系统停机维护公告 — 中国证券业协会`；正文：门户网站将于 **2026-09-30 19:00 — 2026-10-07 20:00** 停机维护，期间暂停相关服务，**10-07 20:00 后恢复**；请求期间全站只回停机公告，取不到数据栏目。
- 上游：`https://www.sac.net.cn/`（中国证券业协会）。

## 细节

- 停机公告口径：维护窗口 `2026-09-30 19:00` 至 `2026-10-07 20:00`，恢复后各栏目可正常访问。
- 恢复后建议入口：门户导航「行业数据 / 统计信息」栏目（CMS 列表 + 附件），配合站内检索按「证券公司经营业绩排名」「经营数据」等关键词定位。

## 坑

1. **别把停机公告页当"协会只有一条公告"**：`200` 但内容是维护通知，说明站点不可用而非无数据。
2. 维护窗口内的 `200` 会**掩盖**真实路径是否有效——复核时必须重跑，别沿用本次结果。
3. 券商本体财务的**替代源**：上市公司券商年报走巨潮（`../business/cninfo.com.cn.md`）；交易所市场统计走 `../business/sse.com.cn.md` / `../business/szse.cn.md`；监管处罚走 `../business/csrc.gov.cn.md`。行业协会口径仅作补充。
4. 与 AMAC/中期协分工：券商资管产品规模看 `amac.org.cn.md`，券商**公司本体**经营数据看本卡。
