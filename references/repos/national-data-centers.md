# national-data-centers —— 国家科学数据中心 20 家入口

- 去哪找：总名录 `https://www.escience.org.cn/data-center`（含依托单位、平台网址、联系电话、标识注册机构码）；各中心直连入口见下方「细节」表。
- 什么时候用：**按学科直达国家级数据中心**（天文 / 海洋 / 极地 / 微生物 / 基因组 / 地球系统 / 气象 / 地震…）；需要领域内权威、长期维护、可引用的国内数据时，先来这里，而不是通用引擎。
- 怎么搜：每个中心有自己的检索台与（部分有）API；**本卡只做入口总表与路由**，检索细节回各自卡片或现场探测。最短路径：`escience.org.cn/data-center` 定位中心 → 进该中心站点 → 用其检索框。
- 覆盖：科技部 / 财政部认定的**国家科学数据中心**体系（2019 起分批），覆盖基础学科、地球环境、生命健康、材料、农业等领域；数据多为长期观测与汇交，带 CSTR 或 DOI。
- 门槛：各中心不同——多数浏览免登录；**下载常需注册 / 实名**（尤其人口健康、基因组）；机构用户部分需 IP 授权。
- 实测：2026-10-03，macOS arm64，curl 逐站探测（桌面 UA，同主机 ≥1.5s 间隔，20s 超时）；状态见下表。
- 上游：`https://www.escience.org.cn/data-center`（名录）

## 坑

- 这些站多为 **SPA + 自建接口**，入口通不代表能 curl；每站要单独探 API（本层只保证「入口可达」）。
- 中文数据中心普遍**下载要注册 / 实名 / 承诺书**，别按国际仓储（免登录直下）的假设写流程。
- 极地与青藏高原两个站点**首次请求易超时**，重试一次再判死。
