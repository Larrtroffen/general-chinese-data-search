# www.sogou.com —— 网页索引（与微信通道互补）

搜狗主站网页搜索，与微信搜索（weixin.sogou.com）同源但索引不同；微信文章标题有时在此可见。

- 去哪找：`https://www.sogou.com/web?query={query}`
- 什么时候用：点查「某关键词的网页版报道」，补微信文章网页版索引（与搜狗微信互补）
- 怎么搜：URL 模板直拼；日期过滤 `&tsn=5&ft=YYYY-MM-DD&et=YYYY-MM-DD`。结果形态：HTML；命中为网页标题 + 摘要，正文需跳转原文；间歇可用、易触发验证
- 覆盖：搜狗网页索引（与 weixin.sogou.com 同源但索引不同）；粒度 = 网页条目
- 门槛：无；被 302 到验证页时换 UA/清 cookie 等待后再试
- 实测：原文未记日期（本机实测：间歇可用、易触发验证；`tsn` 时间过滤被封）
- 上游：站点自身入口（无 repo/Skill 出处）

## 细节

### 用法

```
https://www.sogou.com/web?query={query}
```

- 日期过滤 `&tsn=5&ft=YYYY-MM-DD&et=YYYY-MM-DD`：**与微信搜索一样被封**（302 → 首页/验证码）。
- 实测间歇可用、易触发验证；命中为网页标题 + 摘要，正文需跳转原文。

### 定位

- 点查「某关键词的网页版报道」，与搜狗微信互补。
- 规模检索不要用它。
- 若被 302 到验证页，换 UA/清 cookie 等待后再试。
