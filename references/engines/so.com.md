# so.com —— 标题级检索 + 日期参数

360 搜索。搜狗微信之外的补充通道：可查网页标题、站内检索，带日期过滤参数（但稳定性差）。

- 去哪找：`https://www.so.com/s?q={query}`
- 什么时候用：点查「已知某标题/某站有文，找它的网页版」；站内检索（`site:`）；按日期范围补召回
- 怎么搜：URL 模板直拼；日期范围参数 `&adv_t=YYYY-MM-DD,YYYY-MM-DD`（实测间歇可用）；站内检索 `site:bjchy.gov.cn 试点单位` 之类。结果形态：HTML；命中的多是标题与摘要，正文链接需二次解析（部分为 302 跳转）
- 覆盖：中文网页索引；日期过滤参数尚稳定可用（本机间歇）；粒度 = 网页条目
- 门槛：无（间歇限流/验证码；触发验证时等待数分钟再试）
- 实测：原文未记日期（本机实测：间歇可用、后期常被限流 302/空返回）
- 上游：站点自身入口（无 repo/Skill 出处）

## 细节

### 用法

```
https://www.so.com/s?q={query}
```

- 日期范围参数：`&adv_t=YYYY-MM-DD,YYYY-MM-DD`（实测间歇可用）。
- 站内检索：`site:bjchy.gov.cn 试点单位` 之类。

### 现状（本机实测）

- **间歇可用、后期常被限流**（302/空返回）。
- 命中的多是标题与摘要，正文链接需二次解析（部分为 302 跳转）。
- 触发验证时等待数分钟再试；不可作为主通道。

### 定位

- 用于「已知某标题/某站有文，找它的网页版」这类点查。
- 大规模逐单位检索不要用它（稳定性远差于搜狗微信 wap）。
