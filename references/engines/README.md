# engines/ —— 综合搜索引擎层（索引）

除搜狗微信（主通道）之外的**通用网页搜索**通道，用于「已知某标题/某站有文，找它的网页版」「按关键词放量找转载源」这类点查与补充召回。每个 host 一个文件；`✅/⚠️/❌` 均以本机 curl 实测为准（日期见各文件 `实测` 段）。

## 文件一览

| 文件 | 来源 | 用途 | 状态 |
|---|---|---|---|
| `so.toutiao.com.md` | 头条搜索 | 资讯检索；JSON 接口 + `offset` 翻页 | ✅ 翻页最优 |
| `cn.bing.com.md` | 必应中国 | 中文综搜 + RSS 纯文本流 | ⚠️ 需先预热 |
| `m.sm.cn.md` | 神马搜索 | 移动综搜，可翻页（别名 `so.m.sm.cn`） | ✅ 移动可用 |
| `baidu.com.md` | 百度 | 中文网页兜底；桌面点查、移动翻页 | ⚠️ 翻页遇验证码 |
| `www.sogou.com.md` | 搜狗网页 | 网页索引，与搜狗微信互补 | ⚠️ 间歇可用 |
| `so.com.md` | 360 搜索 | 标题级检索、日期参数 | ⚠️ 间歇限流 |
| `chinaso.com.md` | 中国搜索 | 国家权威源（新华社背景） | ❌ 本机不可用 |

## 选路

**降级顺序（经验）**

1. **头条搜索**（`so.toutiao.com`，JSON + offset）—— 首选，翻页稳、结构化。
2. **必应中国**（`cn.bing.com`，先预热 cookie；要纯文本用 `format=rss`）。
3. **神马**（`m.sm.cn`，iPhone UA，可翻页）。
4. **搜狗网页**（`www.sogou.com`）—— 与微信索引同源，常用于补微信文章网页版。
5. **360**（`www.so.com`）—— 间歇，作最后兜底。
6. **百度** —— 桌面只做单次点查；批量走 `m.baidu.com`。

命中率优先于覆盖广度：不要单通道深翻，换关键词/换引擎重试更划算。逐 host 限频（≤3 次、间隔 ≥1.5s、timeout 20s、桌面/移动 UA 见各文件），触发验证码即换通道，勿硬刚。

**omp 内置 `web_search` 工具**

- 本环境可直接用内置 `web_search`（含 `site:`/`after:`/`intitle:`/`filetype:` 等语法），**适合快速点查，不必写 curl**。
- 但**它不是长期可靠通道**：实测「先可用、约 25 次调用后全 provider 429（限流）」，不适合几百单位 × 多检索式的批量放量。批量仍走本目录的搜索引擎 + 搜狗微信。
