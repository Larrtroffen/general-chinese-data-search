## 坑

1. **不可商用**（作者明确声明），数据来源为公开渠道收集，**权利状态需自行评估**。
2. 数据在**百度网盘**，非直链；网盘链接可能失效，且大批量下载受限速影响。
3. 与 `rmrb-corpus.md` 的"人民日报标注语料"**不是同一物**：本卡的 1946–2003 人民日报为**未标注正文**，适合历时统计，不适合直接做分词/NER 训练。
4. 仓库 2021 年后未更新，语料截止 2016/2003，做"当代"研究需另补（见 `../media/` 电子报抓取）。
5. 仅 README 有元数据，**无逐文件清单**，下载后需自行清点年份与去重。
