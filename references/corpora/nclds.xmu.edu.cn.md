# nclds.xmu.edu.cn —— 教育教材语言资源中心语料库

- 去哪找：语料库检索 `https://nclds.xmu.edu.cn/ylk`（国家语言资源监测与研究教育教材语言资源中心）；中心门户 `https://nclds.xmu.edu.cn/`。
- 什么时候用：要**教育/教材/报刊/网站/博客/口语**等分域语料做**教材语言、语文教育、语言监测**研究；找"国家语委语料库"系列**仍存活的入口**（原"语料库在线"`cncorpus.org` 已失效，见坑）。
- 怎么搜：页面是 ASP.NET 表单，前端脚本 `testjccorpus.js` 用三个 AJAX 端点取数（相对 `/ylk/`）——
  ```
  GET /ylk/getu.aspx?ci=<关键词>        # 初始化一次查询，返回 TOTAL 数
  GET /ylk/getc.aspx?id=<hid1>&cpid=<nav>   # 取某库上下文
  GET /ylk/getd.aspx?pg=<页码>&id=<hid1>&category=<nav>  # 取某库某页数据
  ```
  实测 `getu.aspx?ci=经济` → **301** 重定向到干净 URL `/ylk/getu?ci=经济`（200）；但 GET 返回的是**空壳表单页**（`hid1` 为空），实际结果需页面内 JS 按会话 `POST` 触发 —— 本机 curl 未取到命中。
- 覆盖：8 个分域子库（页面 `allnar` 值 `5|6|7|8|9|10|11|12`）= 国际中文教育教材 / 语文教材 / 学科教材 / 文学作品 / 报纸 / 网站 / 博客 / 口语；检索与词表并列（同页有"义务教育常用词表"等数据服务）。
- 门槛：检索页匿名可打开（实测 200）；**取数需走页面表单/JS**，是否需注册未验证。
- 实测：2026-10-03，macOS arm64，curl 8.x，桌面 UA：`GET https://nclds.xmu.edu.cn/ylk` → 200 / 21,152 B（ASP.NET 页，含 `testjccorpus.js`）；`GET /ylk/testjccorpus.js` → 200 / 7,391 B（读到上述三端点）；`GET /ylk/getu.aspx?ci=经济` → **301** → `/ylk/getu?ci=经济`（200 / 21,169 B，表单页）。
- 上游：教育部语用司/国家语委 语言资源监测与研究中心（教育教材语言资源中心，厦门大学）。

## 细节

### 端点表（从 `testjccorpus.js` 读出）

| 端点 | 参数 | 说明 |
|---|---|---|
| `getu.aspx` | `ci=`关键词 | 发起查询，返回总记录数（TOTAL） |
| `getc.aspx` | `id=hid1`、`cpid=nav` | 取指定库的上下文/统计 |
| `getd.aspx` | `pg=页码`、`id=hid1`、`category=nav` | 取指定库指定页的数据 |
| `nav` 取值 | `5..12` | 对应 8 个分域子库（见上"覆盖"） |

## 坑

1. **"国家语委现代汉语语料库"的招牌入口已失效**：2026-10-03 实测 `http://www.cncorpus.org/`（原"语料库在线"）→ 200 但只是**域名待售停放页**（"您正在访问的域名可以转让!"），**不可用** ❌。要语委系语料请改用本卡（厦大基地）或 BCC / CCL。
2. 厦大站的取数**依赖页面表单与会话**（`hid1` 由 `getu` 回填），裸 curl GET 拿不到结果；稳妥做法是用浏览器打开 `/ylk` 后人工检索。
3. ASP.NET 页面编码为 **GB2312/GBK**（404 页可见乱码），脚本解析注意转码。
4. 是否需注册、单次导出是否限流，未本机验证 —— 当线索用。
