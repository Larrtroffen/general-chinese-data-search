# yuliao.people.cn —— 人民网语料社区

- 去哪找：门户 `https://yuliao.people.cn/`；语料超市/行业语料 `https://yuliao.people.cn/ylsq/cdetail`（示例：品牌/行业问答语料库）。
- 什么时候用：要**权威党媒语料**（《人民日报》等）做**大模型训练/政策研究/舆情分析/学术参考**；需要**合规、可商用授权**的中文语料包（而非盗版网盘）；要"习近平重要讲话/论述"等专题语料包线索。
- 怎么取：站点为**登录制**（首页顶部"登录 | 注册"），语料包按"语料厨房 / 语料超市 / 语料生态 / 服务专区 / 合作入口"分栏展示；具体**下载/授权**须注册后按流程（部分可能收费或走合作）。**本机未登录，未验证下载流程**。
- 覆盖（首页实测文案）：精选《人民日报》等权威报刊，涵盖政治/经济/社会/科教等核心领域，示例语料包"收录高质量文本 **24,370 条**"；另有"十八大以来习近平总书记系列重要讲话、论述、活动、会议、批示、书信、致辞"专题语料包。行业语料库页面含零售服务/家居家电/食品饮料/汽车/健康/工业/法律/金融/房产/康养/教育/文化娱乐/通信传媒等分类（**示例页当前显示"暂无数据"**）。
- 门槛：**需注册登录**；语料包**可能收费或需合作授权**（本机未验证）；属商业/官方语料分发，非免费开放集。

## 坑

1. **登录墙**：首页可匿名看介绍，**取语料必须注册**；本机未跑通下载/授权流程，引用前先确认价格与许可。
2. 页面是**服务端渲染的营销/门户结构**，未见公开 JSON 检索接口；不要指望 curl 批量取数。
3. 与 GitHub/网盘上的"人民日报语料"（见 `rmrb-corpus.md`、`ChineseDiachronicCorpus.md`）分属**合规官方渠道 vs 民间镜像**，正式发论文优先这里拿授权，民间版只作探索。
4. 语料包多为**行业/专题精选**（条数万级），**不等于**全量人民日报历史正文；要全量历年正文另见 `../media/people-daily-crawler.md`。
