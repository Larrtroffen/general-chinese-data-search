# ciefr-hs —— 家庭教育支出的全国固定样本追踪

- 去哪找：项目门户 `https://ciefr.pku.edu.cn/`；数据使用申请说明 `https://ciefr.pku.edu.cn/xshd/xshy/cce1075336cf48be8192c217b56f0f02.htm`；数据入口 北京大学开放研究数据平台 `https://opendata.pku.edu.cn/dataverse/ciefrhs`（数据集 DOI `10.18170/DVN/KE1JYM`）；平台介绍 `https://hdipp.pku.edu.cn/info/1131/1703.htm`。
- 什么时候用：**家庭教育支出与教育负担**、学前教育入园与早教、校外培训/补习、基础教育择校与升学、政府教育补贴、教育公平与家庭背景（收入/城乡/阶层）。关键词：家庭教育支出、教育负担、课外补习、入园率、教育财政、CIEFR-HS。
- 怎么取：在北大开放研究数据平台（`opendata.pku.edu.cn`）用**机构邮箱**注册 → 平台审核 → 搜索「中国教育财政家庭调查」或直入 `/dataverse/ciefrhs` → 按页面流程**在线提交数据使用申请**（原渠道为在线申请表 `http://ciefr-pku.mikecrm.com/WvWZrWp`）→ 签署使用协议后由财政所交付数据。
- 覆盖：2017 第一轮——除西藏、新疆和港澳台外的 **29 个省（区、市）、353 个县、1 428 个村（居）委会、40 011 户 / 127 012 人**；0–6 岁及 16 岁以上在校生 2.1 万、中小学在校生 1.4 万。后续波次见官网报告（2019、2023 年版报告，上游声明）。粒度=家庭 / 个人。
- 门槛：免费但**申请审核制**；须**机构邮箱**（@xxx.edu.cn），个人邮箱需补交工作证扫描件；签数据使用协议；在境外期刊发表时原则上作者须含至少一名财政所人员（上游声明）。
- 实测：2026-10-03，macOS arm64，curl 8.x 桌面 UA：`https://ciefr.pku.edu.cn/` → 200（41 613 B）；申请说明页 → 200（25 170 B，含 mikecrm 申请入口与协议条款）；`https://hdipp.pku.edu.cn/info/1131/1703.htm` → 200（数据文件与申请流程）；**`opendata.pku.edu.cn` 本机 403**（Apache 拒绝，需浏览器 / 校园网）。
- 上游：北京大学中国教育财政科学研究所（CIEFR），与西南财经大学中国家庭金融调查与研究中心合作执行（2017 第一轮）。

## 细节

- 2017 发布内容：**个人数据**（人口学、早教/入园、就读、入学选择、家庭教育支出、政府补贴）、**家庭数据**（收入、支出、资产、负债）、**权重数据**（省份、城乡、权重）；文档含 2017 问卷、变量使用说明、变量编码本。
- 数据平台数据集：`CIEFR-HS`，持久标识 `doi:10.18170/DVN/KE1JYM`；另有 2017 Update 版 `doi:10.18170/DVN/B6HK6Y`（上游声明，本机 403 未核）。
- 联系邮箱：`ciefrhs@ciefr.pku.edu.cn`。
- 相关报告：《中国教育财政家庭调查报告（2019）》《（2023）》（社科文献出版社），可作口径与变量参照。
- 横向对照：北大「文科数智化公共平台」`hdipp.pku.edu.cn` 汇总了该数据集的入口与发布说明，打不开 opendata 时用它看申请要求。

## 坑

- `opendata.pku.edu.cn` 对匿名/外网请求返回 **403**（与 CHARLS 同源限制），申请必须用浏览器或校园网；CIEFR 官网本身畅通，可先读申请说明。
- **县数口径两说**：CIEFR 官网申请说明写「353 个县」，`hdipp.pku.edu.cn` 写「355 个县（区、县级市）、1 428 村居」——引用时以官网当期页面为准。
- 数据**仅限申请人及合作者**，不得转让、不得上传第三方平台；外文发表有作者身份约束，投稿前先看协议。
- 官网页面为老旧 CMS，正文夹杂导航文本，抓取时定位 `发布时间` 后的正文块。
