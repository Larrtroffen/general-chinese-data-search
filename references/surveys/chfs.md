# CHFS —— 家庭金融与资产微观调查

- 去哪找：中心门户 `https://chfs.swufe.edu.cn/`；**数据申请入口** `https://chfser.swufe.edu.cn/data/`（西南财大统一身份认证）；公开数据库 `https://chfs.swufe.edu.cn/sjzx/gksjk.htm`。
- 什么时候用：要**家庭资产/负债/收入/消费/金融行为**微观数据——住房、信贷、保险、支付、创业、小微企业经营；金融学、家庭经济学、反贫困研究。
- 怎么取：走 `chfser.swufe.edu.cn/data/` 申请入口（统一身份认证）；公开数据经审核后提供；西财校内另有绿色通道账号。
- 覆盖：2011 起双年一轮（2011 / 2013 / 2015 / 2017 / 2019 / 2021 / 2023 / 2025…）；家户层为主，含小微企业（CMES）与社区治理（CCGS）配套数据；全国代表性（样本量为上游声明）。
- 门槛：免费；**需注册/实名 + 申请审批**；`chfser` 走西财统一身份认证。
- 实测：2026-10-03，macOS arm64，curl 8.x 桌面 UA：`https://chfs.swufe.edu.cn/` → 200（26,070 B，含「数据申请入口」）；`https://chfser.swufe.edu.cn/data/` → 200（17,945 B，标题「-统一身份认证」）；公告显示 2011–2021 公开数据 2026-07-10 更新、2021 数据 2026-01-31 发布、2025 数据试用版（校内绿色通道）开放。
- 上游：西南财经大学中国家庭金融调查与研究中心。

## 细节

- 与浙大 CFD 同源：CHFS 提供家庭数据、CMES 小微企业数据、CCGS 社区治理调查数据（见 `cfdb.md` 的引用格式要求）。
- 校内绿色通道：有西财教师专用账号合规使用公告（2026-07-20）。
- 中心提供数据投审稿复现支持与成果收集（2026-01-30 公告）。

## 坑

- `chfser.swufe.edu.cn/data/` 是统一身份认证页，**校外用户能否自助注册须按页面提示走**；本机只验证到认证入口。
- 公开数据、试用版、绿色通道数据口径不同，引用时须注明版本与年份。
- 项目站为 `chfs.swufe.edu.cn`，**申请系统在 `chfser.swufe.edu.cn`**（多一个字母，别写错）。
