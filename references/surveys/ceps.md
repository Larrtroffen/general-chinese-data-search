# CEPS —— 初中队列教育追踪调查

- 去哪找：项目门户 `http://ceps.ruc.edu.cn/`；数据检索/下载 `https://www.cnsda.org/`（CEPS 项目页原链 `http://cnsda.ruc.edu.cn/index.php?r=projects/view&id=72810330`，该域本机不通）；新平台 `https://cssd.ruc.edu.cn/`。
- 什么时候用：研究**教育产出与不平等**——家庭/学校/社区对学业、认知与非认知能力、升学的影响；教育学、教育经济学、青少年发展。
- 怎么取：从 CNSDA 检索 CEPS 项目页，按 CNSDA 流程注册/申请；2026-07 起 CSSD 平台的公开数据可实名认证 + 签协议后一键下载。
- 覆盖：基线 **2013–2014 学年**，以初中一年级（7 年级）和三年级（9 年级）两个同期群为起点；从全国随机抽取 **28 个县级单位、112 所学校、438 个班级**，基线约 **2 万名学生**；学生 + 家长 + 教师 + 校领导多主体问卷。
- 门槛：免费；需注册 + 实名 + 签数据使用协议。
- 实测：2026-10-03，macOS arm64，curl 8.x 桌面 UA：`http://ceps.ruc.edu.cn/` → 200（13,149 B）；项目概况页 `…/xmjs/xmgk.htm` → 200（15,593 B，含抽样与队列说明）；`https://cssd.ruc.edu.cn/` → 200（SPA）。
- 上游：中国人民大学中国调查与数据中心（NSRC）`http://nsrc.ruc.edu.cn/`。

## 细节

- 调查手段：问卷 + 综合认知能力测试 + 基本人格测试 + 重要考试成绩（期中/中考/高考）；计划初中阶段逐年追踪，并在毕业后第 1/3/4/7/8/17/27 年追访，周期 30 年；计划第 10 年新起一个 7 年级同期群。
- 已发布 3 期数据（CSSD 2026-08 公告）；另有 2018 年新增小学队列。
- CSSD 平台同时整合 CGSS / CEPS / CLASS / 雇主—雇员匹配数据（见 `cgss.md`）。

## 坑

- 数据入口分散在 `cnsda.org`、`cnsda.ruc.edu.cn`、`cssd.ruc.edu.cn` 三处；`cnsda.ruc.edu.cn` 本机不可达。
- CEPS 是**队列追踪**（同一批学生）而非每期独立抽样，跨期比较须按同期群口径。
- `https://ceps.ruc.edu.cn/` 会 302，**用 HTTP 入口**更稳。
