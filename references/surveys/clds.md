# CLDS —— 劳动力/家庭/社区双年追踪

- 去哪找：数据目录（CNSDA 项目页）`https://www.cnsda.org/index.php?r=projects/view&id=75023529`；项目方中山大学社会科学调查中心 `http://css.sysu.edu.cn/Data`（本机不可达，见「坑」）。
- 什么时候用：要**劳动力个体 + 家庭 + 村居社区三层**的追踪数据——就业与职业流动、收入、迁移、社区结构；做劳动社会学、城乡与流动人口研究。
- 怎么取：从 CNSDA 找到 CLDS 项目页，按 CNSDA 流程注册/申请；或联系中山大学社会科学调查中心数据服务。
- 覆盖：每两年一轮的城乡以村/居为追踪范围的调查（2012 / 2014 / 2016 / 2018…，波次为上游声明）；劳动力个体、家庭、社区三个层次，含追踪与横截面数据。
- 门槛：免费；需注册/申请（CNSDA 渠道）；具体审批口径以项目方为准。
- 实测：2026-10-03，curl 桌面 UA：CNSDA 项目页 `…&id=75023529` → 200（10,732 B，含抽样与层次说明）；`http://css.sysu.edu.cn/`（DNS 解析 202.116.65.66）→ **连接失败**；`http://cssr.sysu.edu.cn/` → **DNS 无记录**。
- 上游：中山大学社会科学调查中心；CNSDA 项目元数据。

## 细节

- CNSDA 项目页字段：项目编号 75023529、简称 CLDS、负责人蔡禾、负责机构「中山大学」、官方网址 `http://css.sysu.edu.cn/Data`、DOI 栏为空、建立 2015-04-06。
- 项目属「985」三期「中山大学社会科学特色数据库建设」专项。
- 中山大学另有旧域名 `cus.sysu.edu.cn`（CFPS 官网友情链接指向其 `sjku.asp`）。

## 坑

- `css.sysu.edu.cn`、`cssr.sysu.edu.cn` 在本机均不可达（前者解析到 202.116.65.66 但连不上）；**CLDS 目前实际入口以 CNSDA 页面为准**。
- CNSDA 元数据止于 2015，波次与样本量信息可能滞后，正式引用前须向项目方核实。
