# edu-finance —— 教育经费与部门预决算

- 去哪找：教育部·**教育经费执行公告**专栏 `http://www.moe.gov.cn/jyb_sjzl/sjzl_jfzxgg/`；教育部·**经费管理**（部门预算/决算）`http://www.moe.gov.cn/jyb_xxgk/xxgk_cwxx/cwxx_jfgl/`；财政部·预算司（全国财政决算 / 中央预算）`http://yss.mof.gov.cn/`
- 什么时候用：要**全国教育经费**口径（总投入、国家财政性教育经费、财政性教育经费占 GDP 比、生均一般公共预算教育经费）；要**教育部部门预算/决算**（含「高等教育支出」等科目）；要在**国家财政决算**里定位「教育支出」（功能分类、中央本级、对地方转移支付）；要**教育统计数据**与**教育事业发展统计公报**；要**单校**决算（→ `universities-open-data.md`）
- 怎么搜：**① 教育经费公告**——专栏按年倒序列出，点进正文（`…/srcsite/A05/s3040/<年月>/t<日期>_<id>.html`）读数字，**统计表在正文附件**（`.doc`，可直下）；**② 部门预决算**——从经费管理专栏取当期页，正文附 **PDF 直链**（`…/srcsite/A05/s7499/<年月>/W0<hash>.pdf`）；**③ 财政决算**——财政部预算司 `/{年}zyjs/`（全国财政决算）、`/{年}zyczys/`（中央预算），各表为 **HTML 表**（含「教育支出」行）。详见「细节」
- 覆盖：教育经费执行情况统计公告 **2006→2024**（专栏实见）；教育部部门预算 **2021→2026**、部门决算 **2019→2025**；教育统计数据按年 `moe_560/{年}/`（实见 2022–2024）；教育事业发展统计公报（实见 2023–2025）；财政部全国财政决算 **2023→2025** 专题。粒度为全国/部本级汇总、功能分类到「教育」及其款级
- 门槛：**全部免费、免登录、可匿名 curl**（教育部站为静态 CMS；附件含 `.doc`/`.pdf`/`.xls`）
- 实测：2026-10-03，macOS arm64，curl 8.x（桌面 UA、`-L`、20s）——教育经费公告专栏 **200 / 23 958 B**；2024 公告页 **200 / 17 385 B**（正文「总投入 68 899.24 亿元、比上年增长 6.66%」），统计表附件 `.doc` **200 / 76 288 B / `application/msword`**；经费管理专栏 **200**（列出 2021→2026 预算、2019→2025 决算）；2025 部门预算 PDF **200 / 7 694 556 B**、2025 部门决算 PDF **200 / 53 019 965 B**（均 `application/pdf`）；教育部数据资料频道 **200**；财政部预算司 **200**；`http://yss.mof.gov.cn/2025zyjs/` **200**，其中「2025 年全国一般公共预算支出决算表」页含「教育支出」字样
- 上游：教育部（`https://www.moe.gov.cn/`，财务司 / 发展规划司）；财政部（`https://www.mof.gov.cn/`，预算司 `http://yss.mof.gov.cn/`）；国家统计局参与联合发布教育经费公告

## 坑

1. **公告发布严重滞后**：「2024 年全国教育经费执行情况统计公告」于 **2025-12-31** 发布（次年年底），做年度分析时注意口径截止与发布日期。
2. **统计表是 `.doc`**（旧 OLE 格式，`application/msword`），非 PDF/xlsx；读取需兼容库，编码多为 GBK 系。
3. **部门决算 PDF 极大**（2025 年度 **≈53 MB**），脚本下载注意超时；预算 PDF ≈7.7 MB。
4. **教育部两个财务栏目并存**：`jyb_xxgk/xxgk/neirong/caizheng/`（列表 JS 渲染，curl 只见导航）与 `jyb_xxgk/xxgk_cwxx/cwxx_jfgl/`（静态可直取）——**用后者**。
5. **口径层次**：全国教育经费（教育经费公告，社会口径）≠ 国家财政性教育经费 ≠ 教育部部门预决算（部本级+所属单位）≠ 中央本级财政「教育支出」（决算表功能分类）≠ 单校决算。引用必须写清是哪一层，四者不可互相替代。
6. **财政部专题按年目录命名**：`{年}zyjs`=全国财政决算、`{年}zyczys`=中央财政预算（易混），且年份目录会随发布滚动新增，不要写死最新年份。
7. 附件 hash 名（`W0…`）不可预测，**一律从正文页取链接**。
