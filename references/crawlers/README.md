## 字段约定

`id` = `crawlers:<owner/repo>`；`name` = 仓库全名；`url` = `https://github.com/<repo>`；`host` = `github.com`；`status` = `unprobed`；`http_code`/`probe_date` 留空待探测；`note` = `★星数 · 语言 · 描述(≤80字)`，过时库追加 `[stale]`；`ref` = 枚举批次。

## 枚举方法与筛选

- 工具：已登录的 `gh` CLI（GitHub 搜索 API，只读），每关键词取前 50 条，按仓库全名去重合并。
- 排除：教程/课程/纯博客、应用仿写/客户端克隆/破解外挂/抢票脚本。
- `[stale]`：仓库已归档，或最近推送早于 2023-10 且 ★<10（仍列出，便于排查）。
- 框架类（scrapy/crawlee/colly/playwright/selenium/puppeteer 等）全部保留。

## 受限项

- 仅覆盖 GitHub，未含 GitLab/Gitee 及站内爬虫工具页。
- `references/meta/awesome-china-mcp.md` 在本批次执行时尚不存在，未能并入其中的采集类条目。
- 星数/描述为枚举时刻快照；`http_code`/`probe_date` 尚未探测。
- 中文关键词检索受 GitHub 中文检索召回率限制，可能漏收小众仓库。
