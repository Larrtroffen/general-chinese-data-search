# cnbksy.com —— 全国报刊索引

上海图书馆《全国报刊索引》的数字平台（纸本《全国报刊索引》的线上版）。收录面覆盖 1816 年至今的报刊篇目，以及晚清期刊、民国期刊、近代报纸的**全文影像**。**机构订阅制**：校园/机构 IP 认证或个人付费，公网裸访问被 WAF 挡。

- 去哪找：
  - 平台首页/检索入口：`https://www.cnbksy.com/`（备用域名 `https://www.cnbksy.cn/`，上游说明称连不上时可换）
  - 篇名库（题录）：站内「篇名检索」频道
  - 晚清期刊全文数据库（1833–1911）、民国时期期刊全文数据库（1911–1949）、中国近代报纸全文库（1850–1951）：站内库别
- 什么时候用：
  - 找 **晚清/民国报刊篇目线索**（篇名、作者、刊名、年份期号、新闻来源、新闻发布地）——即使本馆只有篇名库，也足以做"某年某刊某文"的定位；
  - 需要 **《申报》《大公报》《时报》《民国日报》《中央日报》等近代大报** 的全文影像；
  - 作为 `modernhistory.md`（免费）的**互补**：抗战文献平台偏 1931–1945 及抗日主题，全国报刊索引的报刊面更宽（含晚清、港台）。
- 怎么搜：**本机未能验证其检索 URL/参数——站点的 JS 挑战未通过，检索页与 API 都拿不到。** 依上游图书馆说明，其检索维度为：标题、作者、刊名、分类号、年份及期号、新闻来源、新闻发布地（`检索服务平台`）。可复现的两条路：
  1. **浏览器 + 机构 IP**：直接开 `https://www.cnbksy.com/` 用站内检索（个人用户平台已上线，上游页面称"《全国报刊索引》，一个六十年的老品牌…今天我们将个人用户服务平台呈现给您"）。
  2. **未验证**：是否另有免登录的检索 JSON 接口（如 `/api/…`）——因 WAF 挡在首页，**本次没探到，不要臆测路径**。
- 覆盖：
  - 篇名库：收录 **1816 年至今**报刊篇目，报刊 **15000 余种**（含港台）（人大图书馆页口径）；
  - 民国时期期刊全文数据库（1911–1949）：计划收录 **约 20000–25000 种期刊、近 1000 万篇文献**，多源自上图馆藏；实际开通辑数取决于各馆采购（同济图书馆注明"目前只购买了 1-10 辑"）；
  - 中国近代报纸全文库：**1850–1951 年、约 4000 份中英文报纸**（首图口径）；
  - 晚清期刊全文数据库（1833–1911）：与民国期刊库同属"近代期刊全文"体系。
- 门槛：
  - **机构订阅 / IP 认证**（高校图书馆为主要采购方；成功大学试用通知写明"登入方式：成大校园IP认证"）；部分馆只买篇名库、不买全文库。
  - 公网匿名访问：**被阿里云 ESA 的 JS 挑战拦下（412）**。
- 实测：2026-10-03，macOS 27（arm64），curl 8.x（桌面 UA）。按探测纪律共试 4 次，全部失败：① `curl -L -A '<Chrome 126 macOS UA>' https://www.cnbksy.com/` → **412 Precondition Failed**，`Server: ESA`，2.4 KB 挑战页（`$_ts` 混淆脚本 + `_$eN()`）。② 换 UA（Chrome 124 Windows）+ `Referer: https://www.cnbksy.com/` + `Accept-Language: zh-CN` → **412**（同样挑战页，`meta id="dSXrRAhldgEr"` 值每次不同 = 动态 JS 挑战）。③ `http://www.cnbksy.com/`（降级到 http）→ **412**（被 301/统一到 https 再拦）。④ `https://www.cnbksy.cn/` 与 `/robots.txt` → **412** / **302**（robots 也被重定向到挑战）。→ 结论：**本机 curl 受限**（阿里云 ESA 边缘 JS 挑战，非 UA/Referer 能绕），需要**真实浏览器**（且大概率还需机构 IP/账号）才能看到检索页；headless 浏览器同样会被识别，需人工介入。
- 上游：https://www.cnbksy.com/ ；上海图书馆平台（成功大学试用通知）https://chinese.ncku.edu.tw/p/404-1142-287285.php ；同济图书馆库介 https://www.lib.tongji.edu.cn/index.php?classid=11981&id=175&t=show ；首图库介 https://www.clcn.net.cn/resources/default/detail?id=296

## 坑

1. 挑战页是**动态下发**的（`meta id` 随机、`$_ts.cd` 每次不同），不要写死解析规则。
2. `www.cnbksy.com` 与 `www.cnbksy.cn` 是同一套防护，换域名没用。
3. 采购粒度差异极大：同一库名在不同图书馆可能是「篇名」也可能含「全文」，查文献前先确认所在机构的**已购辑数**。
4. 若只要线索不要求全文，优先用免费的 `modernhistory.md`（1931–1945 主体）与国图 `mg.nlcpress.com`（民国图书，付费）、`nlc.cn.md`（民国期刊题录）。
