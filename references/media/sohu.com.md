# sohu.com —— 搜狐转载通道

政府/党媒稿件常被搜狐转载，正文可直接抓，是微信原文拿不到时的替补通道。

- 去哪找：`https://www.sohu.com/a/{id}_{uid}`；移动版 `https://m.sohu.com/a/{id}_{uid}`
- 什么时候用：微信原文拿不到时的替补引文；搜狗微信结果里带"搜狐"转载链接时
- 怎么搜：搜狗微信结果常带"搜狐"转载链接；或 `web_search`：`site:sohu.com {标题关键词}`
- 覆盖：政府/党媒稿件转载；示例含顺义"先期试点旺泉街道"稿
- 门槛：无
- 实测：2026-10-02，macOS + curl（`m.sohu` 更稳，状态见 media/README 索引）
- 上游：<https://www.sohu.com/>

## 细节

- 示例（顺义"先期试点旺泉街道"稿）：`https://www.sohu.com/a/253327640_99958848`。
- 取正文：

  ```bash
  curl -s -m 25 -A 'Mozilla/5.0 …' 'https://m.sohu.com/a/253327640_99958848'
  ```

## 坑

- 移动版 `m.sohu.com` 比 PC 版更稳（PC 版偶发验证码/跳转）。
- 正文在 `<article>` / `.text` 节点，按实际结构提取；转载文保留原媒体署名与日期。
- 转载件可作微信原文的替代引文源（正文一致时）。
