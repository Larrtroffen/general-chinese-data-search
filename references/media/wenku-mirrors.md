# wenku-mirrors —— 文库类转载站取全文

**适用**：实施方案、改革方案、工作报告这类**官方未全文公开**、但被网民上传到文库站的文本（典型案例：《关于党建引领街乡管理体制机制创新实现"街乡吹哨、部门报到"的实施方案》：区级版本官方未公开，市级版本在文库站拿到全文）。用法 = **先用搜索命中（必应/头条精确短语），再 curl 直取**，最后与官方口径交叉比对。

- 去哪找：`51jzrc.cn` 无忧文档网、`renrendoc.com` 人人文库、`docin.com` 豆丁、`doc88.com` 道客巴巴、`doc.quark.cn` 夸克文档、`wenku.baidu.com` 百度文库；检索入口 必应精确短语 / 头条·神马搜索
- 什么时候用：官方未全文公开的方案/报告全文（如区级实施方案）；原文被删时的"影子通道"
- 怎么取：先用搜索命中（必应/头条精确短语），再 curl 直取；`51jzrc` 直接 curl；其余站点先试 `read` 工具
- 覆盖：6+ 文库站（51jzrc / 人人文库 / 豆丁 / 道客巴巴 / 夸克 / 百度文库）
- 门槛：无（部分站点需登录/积分/滑块）
- 实测：2026-10-02（51jzrc 复测，macOS + curl）；其余站点状态来自 2026-10-01 会话实测，标 ⚠️/未验证的未复测。
- 上游：<https://www.51jzrc.cn/>

## 细节

### 站点矩阵（实测）

| 站点 | 状态 | 取全文方式 | 现象 |
|---|---|---|---|
| `51jzrc.cn` 无忧文档网 | ✅ **可 curl 直取全文** | `curl -sk -m 25 '<文章URL>'` | 2026-10-02 复测：200 / 43,873B，标题《关于党建引领…实施方案》，正文约 5,200 字（含"三、工作要求"）；2026-10-01 首次取得 5,525 字全文。带 `-L` 与服务端协商编码即可；无 UA/Referer 时甚至走 http 反而不拦 |

### 检索入口（怎么找到文库页）

1. **必应精确短语**（引号包裹整句、以"未公开文件"里的特征短语为查询）——curl 返回空壳，需**可见浏览器**（playheadless 实测可用）：首次命中就同时给出官方新闻页 + 若干文库站（51jzrc/renrendoc/docin/doc88/quark/百度文库）。
2. 头条/神马搜索同样可做精确短语点查（见 `../engines/`）。
3. 命中后：`51jzrc` 直接 curl；其余站点先试 `read` 工具；都不行再考虑人工浏览器。

## 坑

- **脱敏**：文库上传版本可能被上传者脱敏（`XX市委`、`XXXXXXXX`）→ 只能作交叉比对材料，关键人名/数字要另找官方源核实。
- **权威性**：文库站属二手转载，引用时标明"转载自文库站，与官方口径已交叉比对"；版本可能被改动。
- **时效**：此类站点存活率一般（道客巴巴 302/失效常见），拿到即落盘（`fetch.py --out`）。
- 检索关键词要选**低泄漏短语**（如"街乡吹哨、部门报到"实施方案里的成句），否则召回大量无关文档。
