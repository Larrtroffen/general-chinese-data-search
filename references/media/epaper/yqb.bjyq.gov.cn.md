# yqb.bjyq.gov.cn —— 延庆报 PDF 数字报

区报数字报是把"某区 2018 年逐期报道"拉全的最好通道之一：URL 规则化、可直接下载、无反爬。

- 去哪找：站点 `http://yqb.bjyq.gov.cn/`；PDF 直链 `http://yqb.bjyq.gov.cn/resfile/YYYY-MM-DD/NN/NN.pdf`
- 什么时候用：逐月/逐期找区级部署会、试点单位名单、表态发言（如 2018-03-30 第 2 版"7 个试点单位"）
- 怎么取：按日期构造 PDF URL 直接下载（`YYYY-MM-DD` 出版日期、`NN` 版面号，`02` = 第 2 版）；或先抓当期目录页拿版面号
- 覆盖：2018 全年 151 期、604 版可全量拉取
- 门槛：无
- 实测：2026-10-02，macOS + curl，PDF 直链可下载（状态见 epaper/README 索引）
- 上游：<http://yqb.bjyq.gov.cn/>

## 细节

- 示例：`http://yqb.bjyq.gov.cn/resfile/2018-03-30/02/02.pdf`（2018-03-30 第 2 版）。
- 全量枚举：日期从 `2018-01-01` 到 `2018-12-31` 按出版周期（周三报/周五报等，实际为每周约 3 期）逐日试取；每期版面约 2–8 版。或先抓当期目录页（首页/日期索引）拿版面号，避免盲试。
- 下载后用 `pdftotext`（poppler）或 Python（pdfplumber/pymupdf）转文本，再 grep 关键词（如"试点单位""吹哨报到"）。

## 坑

- PDF 是扫描版时需要 OCR（部分版面是排版 PDF，文本层可直接抽）。
- 同类数字报：昌平报、房山报、密云报（见 `xepaper.com.md`）等各有独立域名，URL 规则需逐个探测。
