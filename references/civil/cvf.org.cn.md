# cvf.org.cn —— 志愿服务协同平台与志愿者数据

- 去哪找：**中国志愿服务协同平台**（中央社会工作部建设）网页端 `https://www.cvf.org.cn/xtpt/#/login`；门户 `https://www.cvf.org.cn/`；微信小程序「中国志愿服务协同平台」。旧站**中国志愿服务网** `https://chinavolunteer.mca.gov.cn`（民政部，2017 上线）**已于 2026-07-20 全面停止服务**，数据迁往协同平台。
- 什么时候用：要**志愿服务组织（队伍）注册名录/备案**、**志愿服务项目（活动）发布与招募**、志愿者注册与服务时长记录、**「中国志愿服务网」历史数据找回**（2025-05 及以前）。
- 怎么搜：**网页端/小程序登录后站内检索**（`/xtpt/#/` 为 SPA，登录门后才有组织/活动数据）；历史数据走登录后「统一用户引擎登录管理 → 跨平台历史活动记录」，或「找回中国志愿服务网数据」专属通道。未登录无匿名 JSON 检索接口（本次探测未能从 SPA 壳挖到可用 XHR 端点，**仅浏览器**）。
- 覆盖：全国志愿者（注册年龄 6–85 周岁）、志愿服务组织（队伍）、志愿服务项目/活动、服务时长与记录；协同平台 **2025-12 全面上线**，2025-05 之前「中国志愿服务网」数据自 2026-06-19 起可申请找回（2025-05 后数据约 2026-08 底起可找回）；粒度=个人/组织/项目级。
- 门槛：**需注册登录**（志愿者用居民身份证实名；志愿服务组织注册须填**管理机构邀请码**）；旧站关联系统（含地方子站、「中国志愿」APP、支付宝小程序）自 2026-06-19 停止注册/发布功能。
- 实测：2026-10-03，macOS arm64——`dig chinavolunteer.mca.gov.cn`（@8.8.8.8/@223.5.5.5/@119.29.29.29）→ 仅 **CNAME `chinavolunteer.mca.gov.cn.bsclink.cn`，无 A 记录**（站点已下线）；`GET https://www.cvf.org.cn/` → **200**（`<title>中国志愿服务</title>`）；`GET https://www.cvf.org.cn/xtpt/` → **200**，23 398 B（`<title>中国志愿服务协同平台</title>`，Vue SPA 壳）。
- 上游：中央社会工作部；民政部关停公告（2026-06-19，澎湃新闻/新华网转载）；平台官网 `https://www.cvf.org.cn/xtpt/`；旧站 `https://chinavolunteer.mca.gov.cn`（已停）。

## 细节

- 关停时间线（旧「中国志愿服务网」公告）：
  - 2026-06-19 0 时起：停止志愿者/队伍注册与项目发布（含地方子站、「中国志愿」APP、支付宝小程序）；
  - 2026-07-05 0 时起：仅保留志愿者、队伍数据查看下载权限，「运行中」项目统一结项；
  - 2026-07-20 0 时起：全面停止服务。
- 承办主体：协同平台由**中央社会工作部**建设；域名落在 `cvf.org.cn`（中国志愿服务门户），登录页 `https://www.cvf.org.cn/xtpt/#/login`。
- 平台定位：数据协同——对接各地各部门自建志愿服务平台，未自建地区/部门可直接使用；「谁使用、谁管理、谁负责」。

## 坑

1. **旧域名已死**：`chinavolunteer.mca.gov.cn` DNS CNAME 到 `bsclink.cn` 且无 A 记录，curl/浏览器均不可达，勿再作取数入口。
2. **数据不完整迁移**：协同平台只找回 2025-05 之前的旧站记录，2025-05 后数据迁移滞后；跨平台（除旧站外）时长暂不支持同步。
3. **组织注册要邀请码**：未接入协同平台的地方，其志愿组织无法注册；这类地区仍用本地志愿服务信息平台。
4. 协同平台是 SPA，组织/项目检索走登录态 XHR；本机未从壳页挖到可直连接口 → 标注「仅浏览器」。
